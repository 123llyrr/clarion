Realand source provenance
Recorded: 2026-10-14

Realand began as a project derived from niri, as identified by its owner.
Upstream project: https://github.com/niri-wm/niri
Historical project URL: https://github.com/YaLTeR/niri
Original work is credited to the niri authors and contributors. The precise
initial upstream commit is not identified by this checkout's local history.

Realand uses the GPL-3.0-or-later license declared in Cargo.toml. The existing
root LICENSE text and retained upstream source notices remain part of the
project. This provenance record does not replace those notices.

The Realand independent-core migration replaces desktop controllers and
numeric policies with realand-core and keeps platform adapters for client,
protocol and device resources. It does not erase the project's historical
origin or claim that retained platform code was authored from scratch.

Smithay, DRM/KMS, libinput, Wayland, Vulkan and other infrastructure retain
their own dependency identities and licenses. Additional effect and Shell
sources are recorded separately in this directory.

The Catalina analysis records evidence for selected mechanisms. Realand does
not embed Apple's analyzed executable code; unknown animation parameters are
identified as Realand parameters rather than verified macOS curves.

Independence note, 2026-10-17
-----------------------------
This repository no longer tracks the niri upstream. Measured against
niri-wm/niri at 45739bc: of the 122 Rust files under src/ that share a path
with upstream, 112 no longer share an implementation, 3 differ only by the
project rename, and 7 are unchanged generic helpers. Another 160 Rust files
exist only here. The wiki has diverged similarly.

Maintenance is independent of upstream release cadence. Individual fixes may
be taken from niri, but there is no sync and upstream behaviour is not the
reference for Clarion behaviour.

This note records a maintenance decision. It does not reduce or replace the
attribution that GPL-3.0-or-later requires for the derived code.
