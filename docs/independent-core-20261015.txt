独立核心与设备边界

realand-core 的生产依赖只有 smallvec，不依赖 Smithay、Wayland 或 GPU。稳定窗口、
输出与空间身份，焦点、层级、最小化、模式恢复、普通拖动、拖放悬停、桌面切换、
概览/Spread/Stage、画布惯性和视口目标等语义由纯核心控制。
浮动、滚动平铺、动态 BSP 使用统一纯布局策略，平台适配器应用实际客户端约束
和协议 configure，保留各模式的位置记录、真实 Tile/客户端与设备资源。

输出使用不可变场景计划及 renderer-specific SceneSnapshot；设备绘制入口通过
受限 FramePort/DevicePort 访问场景与反馈。平台协调器负责协议、设备和完成事件。
没有另选一个生产核心的运行开关。来源、版权与许可证继续保留，独立设计不代表
抹除历史来源，也不是对全部调用图的形式化证明。

调度和本轮缺陷修复

每个输出使用独立时钟、预计呈现时间与帧预算。动画未来取样与真实状态推进分开；
打断/反向承接位置和速度，连续移动按帧合并，离散输入边界保持顺序。
本轮修复画布相机预测与场景位移方向不一致的问题；保留下一次真实推进及手势
首帧的数值断言。另修复 FIFO 估计帧结束后遗留定时器，覆盖提交、估计 vblank、
超时和表面销毁，保留其他未到期帧的独立截止时间。

GPU 主线程改造

着色器 CPU 编译与 GPU 管线准备通过有界任务执行；准备线程只持有设备和程序
资源，不拥有桌面或完整 NativeRenderer。格式扩展、YUV 管线及 RGBA 中间效果
管线未就绪时仅推迟相应场景，保留已有像素，由实际完成事件唤醒重试。
驱动编译在缓存锁外执行；旧格式与其他已准备输出可以继续绘制。

帧、上传和完成任务分别限制容量，提交前预留；容量不足返回 Busy，不在主线程
等待旧 GPU 工作。GPU 推迟保留真实的长呈现间隔，诊断不会将其归为无损伤空闲。
窗口纹理携带精确的每次 Wayland 缓冲附件租约；旧场景和同存储新附件都保持到
真实 GPU 完成，空闲时也可释放，不依赖后续鼠标操作或重绘。

GPU 提交后同步 FD 导出失败时，先把提交及全部资源交给预留的完成队列，再返回
原错误。新增故障注入覆盖 8 次未完成提交、零调用线程 fence 等待、第 9 帧拒绝、
空闲释放与恢复。DRM 渲染失败会更换缓冲池槽位；独立复核未发现旧目标跨队列
提前复用的具体路径。

截图/读回、PNG/文件、配置与会话 JSON、光标资源、gamma FD、键盘文件和运行中
Xwayland 探测使用有界异步任务；核心状态保持主线程所有权，完成时检查代次、
身份和锁屏/场景 epoch。显式同步、提交时序、FIFO、Vulkan 预热及 damage 修复保留。
