# Downloads 扇形显示与边界

显式选择“扇状”与“自动”是不同设置。先前 Realand 把二者共用的“最多八个文件”条件应用到所有扇形，因此实际下载目录项目较多时，明确选择扇形仍变成网格。本轮将显式选择与自动选择分开。

底部 Dock 有足够空间时，显式扇形展示一组有界文件图标，以及一个打开下载目录的终点；目录项目多于当前可显示的图标时，终点标记为“在文件管理器中显示更多”。可用高度决定数量，目前最多八个文件图标。终点始终可以点击，按 End、Enter 也可以打开目录。键盘只访问实际呈现的文件和终点，不会打开藏在绘制范围外的条目。Up 对应扇形中屏幕上方的下一个图标，Down 回到下方。

原生 Dock 与主面板使用独立 Flutter 视图，各自保留焦点历史。下载面板初次附着后显式请求自己的键盘焦点，避免已有菜单焦点让 `autofocus` 失效。请求仅在打开面板时执行，普通重绘不会抢走弹出菜单焦点；销毁面板时释放节点。两套 `MaterialApp` 的回归覆盖旧主面板焦点、Dock 焦点和下载面板打开后的 End、Enter 操作。

“自动”仍会根据数量和可用空间选择扇形或网格。侧边 Dock、过窄或高度不足的输出保留网格回退，以保证图标、标签和操作目标在屏幕内。八项上限、间距、角度、展开的 320 ms 与收起的 220 ms 均为 Realand 当前参数，尚不能当作 Catalina 的私有实现参数。

扇形文件采用分离的大图标和文件名胶囊，沿弯曲路径展示；原生 Dock 图标中心传入面板，图标从该位置展开。靠边时标签方向与曲线镜像并约束在面板内。关闭按钮、Esc 和成功打开文件会先收起，再调用当前面板的关闭回调；减少动态时立即完成。控制器仍负责过期面板回调保护，以及点击背景、全局面板切换的外层呈现。

目录服务的 256 项枚举上限保持不变。可显示项目是已枚举并排序的内容，不是全目录的全量 Quick Look 缩略图；“显示更多”通过 GIO 打开完整目录。未将 POSIX ctime 当作创建日期或添加日期。

## 参考证据

Catalina 镜像内的 `Dock.app/Contents/Resources/DockMenus.plist` 将 `FAN`（6002）与 `AUTOMATIC`（6001）列为不同目录菜单命令，同时提供 `GRID`、`LIST` 和打开目录操作。SHA-256 为 `1a4a7bf8af64006dd101fb9d01dc0ea803dbdbccfeaa065c58b29437d42b5314`。资源证明这些选项的区分，不能证明扇形容量、曲线、帧时序或大量条目时的每个运行细节。

[Catalina 对应 Dock 帮助](https://support.apple.com/en-gb/guide/mac-help/mh35859/10.15/mac/10.15) 说明 Downloads 作为目录叠放，点击内容打开文件。[Apple 的目录使用帮助](https://support.apple.com/en-mz/guide/mac-help/mchl231f08fb/mac) 进一步列出独立的 Folder/Stack、排序及 Fan/Grid/List 选择；此后者是当前帮助，不用它冒充 Catalina 运行测量。Catalina 专用目录帮助地址本轮无法取得，因此明确不声称已经观测或还原苹果的大量文件精确截断数量。

回归覆盖显式 Fan 的 9/24/128/256 项请求、自动回退、可见文件上限、更多入口、键盘方向、反向收起、减少动态及迟到启动回调。原生像素与边缘命中检查由本轮私有 Wayland 测试进一步验证。

原生 GPUI Shell 已将同一套“显式选择与自动选择分离”的语义用于用户固定的 Dock 文件夹：目录快照上限 256、隐藏项跳过、列表/网格/扇形/自动四种布局，自动布局参考数量与可用空间。扇形沿贴靠边反方向按抛物线展开，只绘制图标、文件名胶囊和操作按钮，不增加全屏遮罩或模糊，Dock 保持完整可见。该实现是用户固定文件夹，不是 Downloads 系统叠放；`show_downloads` 仍未接线。
